# リノアメンテナンスツール 簡易仕様書

## 1. 概要

太陽光発電設備の点検情報を入力し、Google スプレッドシートへ保存する Google Apps Script（GAS）Web アプリです。
点検写真は Google ドライブへ保存し、Google ドキュメントのテンプレートから点検報告書 PDF を作成できます。

## 2. 構成

| ファイル | 役割 |
| --- | --- |
| `Code.js` | GASバックエンド。シート保存、Drive保存、PDF作成、メール送信 |
| `Index.html` | 入力画面、画像圧縮、履歴表示、PDFプレビュー、メール送信操作 |
| `appsscript.json` | GAS実行環境、タイムゾーン、権限設定 |
| `deploy.ps1` | `clasp push` と GitHub へのコミット・プッシュ |
| `.clasp.json` | 対象GASプロジェクトの script ID |

## 3. 処理フロー

1. 利用者が担当者、施主名、住所、メール、判定、コメント、詳細数値を入力する。
2. 写真を選択すると、ブラウザーの Canvas API で横幅最大1000px、JPEG品質0.7へ圧縮する。
3. 保存ボタンを無効化し、圧縮画像と点検情報を `saveInspectionData` へ送信する。
4. GASが画像をDriveの出力フォルダへ保存し、画像URLと点検情報をシートへ追記する。
5. 履歴画面で内容を確定し、PDFプレビューで内容を確認する。
6. 確認後にPDFを保存し、保存済みPDFと送信先を確認してからメールを送信する。

## 4. スプレッドシート仕様

シート名は `点検データ` です。1行目に次の14列を作成します。

| 列 | 項目 | 内容 |
| --- | --- | --- |
| A | ID | `REN-...-2026` 形式の識別子 |
| B | 点検日時 | 保存日時 |
| C | 担当者 | 点検担当者 |
| D | 施主名 | 顧客名 |
| E | 現場住所 | 発電所所在地 |
| F | メール | 送信先メールアドレス |
| G | 判定 | `〇 良好`、`△ 経過観察`、`× 要修繕` |
| H | コメント | 総合所見 |
| I | 全体写真 | Drive URL |
| J | パワコン写真 | Drive URL |
| K | 異常写真 | Drive URL |
| L | 詳細数値 | 電気特性などの詳細 |
| M | ステータス | `下書き`、`確定`、`PDF保存済み`、`メール確認`、`送信完了`、`送信エラー` など |
| N | PDF_URL | 生成したPDFのDrive URL |

## 5. PDF仕様

マスターGoogleドキュメントをコピーし、次のタグを入力データへ置換します。

- `{{施主名}}`
- `{{現場住所}}`
- `{{点検日時}}`
- `{{担当者}}`
- `{{総合判定}}`
- `{{見解コメント}}`
- `{{詳細数値}}`
- `{{現場全体写真}}`
- `{{パワコン写真}}`
- `{{異常箇所写真}}`

置換後に `doc.saveAndClose()` と `SpreadsheetApp.flush()` を実行してからPDFへ変換します。
プレビュー用PDFは確認後にゴミ箱へ移動し、メール送信用PDFはDriveへ保持します。

## 6. 主なGAS関数

| 関数 | 用途 |
| --- | --- |
| `doGet` | Webアプリ画面を表示 |
| `setupOutputFolder` | PDF・画像保存用Driveフォルダを作成 |
| `setupSystem` | シートとPDFテンプレートを初期作成 |
| `saveInspectionData` | 画像保存と点検データ追記 |
| `previewPdfReport` | PDFを生成してプレビュー用Base64を返す |
| `sendReportEmail` | PDF作成、メール送信、状態更新 |

## 7. 初期設定

1. GASエディタで `setupOutputFolder` を一度実行する。
2. 新規環境では `setupSystem` を実行する。
3. Drive、スプレッドシート、ドキュメント、Gmailの権限を承認する。
4. Webアプリをデプロイし、発行されたURLを利用する。

`appsscript.json` のWebアプリ設定は、現在 `USER_DEPLOYING` 実行、アクセス `ANYONE` です。組織のセキュリティ方針に応じて見直してください。

## 8. 更新方法

```powershell
.\deploy.ps1
```

このスクリプトは、`clasp push` によるGAS反映、Gitコミット、GitHubへのプッシュを順番に実行します。
公開済みWebアプリへ反映するには、GASエディタの「デプロイを管理」から新バージョンを選択して再デプロイしてください。
`clasp push` だけでは公開URLのバージョンは更新されません。

## 9. エラー確認

PDF生成、画像読み込み、フォルダアクセス、保存処理では `Logger.log` と `console.error` に詳細情報を出力します。
GASエディタの「実行数」から失敗した実行を開き、関数名、Drive ID、テンプレートID、出力フォルダID、エラーメッセージを確認してください。

## 10. 制約

- 写真は送信前にJPEGへ変換され、横幅最大1000pxで圧縮される。
- Drive、ドキュメント、Gmailの権限がない場合は処理できない。
- 暗号化された外部PDFを読み込む機能は実装していない。
- 大量データや大容量ファイルの一括処理にはGASの実行時間・通信制限がある。
